Regras
Botões usam o próprio estado Loading do Button — não coloque um Spinner solto ao lado.
Se a espera passar de 2 s, mostre uma mensagem dizendo o que está acontecendo.
Ring é o padrão; Dots para contextos de conversa (digitando, IA pensando).
Para carregamento de página use Skeleton; para tempo conhecido use Progress.
