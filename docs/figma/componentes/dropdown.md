## Dropdown · Documentação

SELEÇÃO
Dropdown & Combobox
Dropdown para escolher entre poucas opções conhecidas (ordenar, filtrar); Combobox quando a lista é longa e a pessoa precisa digitar para encontrar. Ambos usam Menu Item, Menu Label (mono) e Menu Divider — os mesmos do Profile Menu e do Action Menu.
Gatilho
Prefix ("Ordenar: Último acesso ⇕"), Simple, Icon e Ghost. Fundo segue os modos Field (Default/Flush/Raised). Aberto e Focus usam borda 1px + halo 4px.

Regras
— Até 7 opções: Dropdown. Mais que isso ou lista dinâmica: Combobox.
— Opção ativa com check à direita, nunca só cor.
— Ações destrutivas (Excluir, Sair) ficam por último, em vermelho suave e separadas por divisor.
— Atalhos de teclado com Kbd; contagens com Badge; títulos de grupo em JetBrains Mono.
