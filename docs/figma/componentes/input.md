Input
Campos de formulário do Midas: Input (Text, Password, Search, Number, Select), Search Bar, Select Menu, Textarea, Tag Input, Code Input (OTP) e File Upload. Regra visual: borda fina e clara (border/subtle) + sombra esfumaçada (elevation/control). Foco = borda 1px + halo 4px. Toda variação tem Tone Brand (cyan) e Neutral (sem cyan).
Tamanhos
SM 40 · MD 48 (padrão, desktop e mobile) · LG 56 (destaque, busca principal, hero). Altura via size/control/lg · xl · 2xl.

Forma (Shape)
Todo campo tem Shape = Rounded (raio 6, padrão) ou Pill (totalmente arredondado), igual aos Buttons. Pill: Input, Search Bar, Date Field e Tag Input viram cápsula; Textarea e File Upload ganham raio grande (20 e 28) porque cápsula não funciona em área alta; Code Slot vira cápsula; Select Menu acompanha com raio 20. No Pill, o padding lateral cresce +4 e rótulo/apoio recuam 18px para alinhar com o texto de dentro. Regra: não misture formas na mesma tela — use Pill em telas com Buttons Pill (marketing, onboarding, busca) e Rounded em telas densas (painéis, tabelas, formulários longos).

Campos no modo escuro
Coleção de variáveis Field com 3 modos para o fundo dos campos (token field/surface). Aplique o modo no frame da tela ou do formulário: Default — campo mais escuro que o fundo (atual); Flush — campo da mesma cor do fundo, como no modo claro; Raised — campo mais claro que o fundo. No modo claro, Default e Flush são iguais.
